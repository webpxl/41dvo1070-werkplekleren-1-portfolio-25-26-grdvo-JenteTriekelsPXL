Reflectie

Wat heb ik geleerd?

Ik heb veel geleerd in dit project/semester, waaronder nieuwe technische vaardigheden en inzichten in designprincipes. Zoals principes hoe ik gebruiksvriendelijke interfaces kan ontwerpen en hoe ik mijn code efficiënter kan schrijven. De designprocessen hebben me geholpen om mijn creatieve denkvermogen te verbeteren en ik heb geleerd hoe ik beter kan samenwerken in een teamomgeving.

Wat ging goed?

Ik denk communicatie met groepsleden beter dan verwacht ging. Ik ben niet de beste communicator, maar ik heb mijn best gedaan om open en duidelijk te zijn over mijn ideeën en feedback. Anders ging het aspect van designen ook goed. Ik ben tevreden met hoe mijn ontwerpen eruit zien en hoe ze functioneren.

Wat kan beter?

Het coderen kon in mijn geval beter. Ik had heel vaak aan andere groepsgenoten moeten vragen om hulp bij het coderen. Ik heb ook gebruik gemaakt van het toegelaten AI hulpmiddelen zoals ChatGPT en GitHub Copilot. Ik wil hier oprecht beter in worden maar ik heb hogere interesses in designen.

Belangrijkste inzicht:

Mijn belangrijkste leerpunt is dat ik moet blijven oefenen met coderen om mijn vaardigheden te verbeteren. Voor de rest ben ik tevreden met mijn designvaardigheden en wil ik me daar verder in ontwikkelen.

Situering binnen DVO

Relatie tot de opleiding

Dit project sluit goed aan bij de doelstellingen van de opleiding Digitale Vormgeving, omdat het me in staat stelt om zowel mijn technische als creatieve vaardigheden te ontwikkelen. Het project heeft me geholpen om een beter begrip te krijgen van hoe ik digitale producten kan ontwerpen die zowel functioneel als esthetisch aantrekkelijk zijn. Qua competenties heb ik mijn vaardigheden in user experience design, front-end development en projectmanagement verder kunnen ontwikkelen.

Toegepaste vaardigheden

  • Design: Futuristische cyber stijl met hovers en animerende lichten.
  • Development: HTML-structuur, Single page scroll, CSS layout technieken, Responsive design, JavaScript functionaliteiten.
  • Tools: WebStorm, Claude AI, Figma, GitHub Copilot, ChatGPT.

Toekomstige doelen

Ik wil me verder ontwikkelen in designen, met een focus op user experience en visueel ontwerp. Coderen kan ik lichtelijk verder opnemen in mijn eigen tijd om de technieken te verbeteren, maar mijn passie ligt meer bij het creatieve aspect van digitale vormgeving.
