## Beschrijving
Voor deze opdracht heb ik mijn visueel ontwerp omgezet naar een werkende portfolio-website.  
De website is opgebouwd als een single-page met verschillende secties, waaronder profiel, tijdlijn, skills, hobbies, projecten en doelen.  

Daarnaast is er een aparte pagina voorzien voor de **reflectie en situering binnen Profiel DVO**, zoals gevraagd in de opdracht.
